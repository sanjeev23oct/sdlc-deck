What is a skill?

A written set of instructions the agent loads when a task calls for it. It's how we teach the agent our way of working.

It is a fileA folder with a SKILL.md, kept in the repo and reviewed like code.
It has one jobFor example: build one API controller, then stop.
It is sharedEveryone on the team gets the same instructions.
