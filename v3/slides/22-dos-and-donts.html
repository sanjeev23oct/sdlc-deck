Do's and don'ts

The agent sees whatever you give it, so give it only code

Do

  • ✓Use Claude Code for development onlyCode, tests, specs and reviews. Not for HR, finance or sangat data.
  • ✓Work through skills and agentsUse reviewed skills from the ai-assets library, not one-off prompts.
  • ✓Check what you paste or attachLogs, screenshots and files often hold names, phones or IPs.
  • ✓Use masked or synthetic dataTest data is made up. Real records stay in the database.

Don't

  • ✕Share personal dataNo names, phone numbers, addresses, IDs or photos of people.
  • ✕Share IPs, hostnames or secretsNo server addresses, passwords, tokens, keys or connection strings.
  • ✕Vibe codeNo unreviewed code from loose prompts. Every change has a spec and a checker.
  • ✕Install skills or agents from the internetNothing runs until InfoSec has reviewed it.
