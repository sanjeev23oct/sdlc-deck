Do's and don'ts: getting started

Every team starts from the ai-assets library

New project

Start with the guardrails in place.

  1. Copy the starter kitTake it from the ai‑assets project into your repo.
  2. Follow the setup instructionsThey are in the ai‑assets project and cover skills, agents and settings.
  3. Work through the skillsThe skills set how each task is specified, built and checked.

Legacy project

Add skills step by step, without a rewrite.

  1. Clean up firstMove secrets and IPs out of the repo and config into a vault.
  2. Copy the starter kitTake it from the ai‑assets project into your repo.
  3. Follow the setup instructionsUse the steps for existing projects in ai‑assets.
  4. Apply skills to new changesExisting code stays as it is until a change touches it.
