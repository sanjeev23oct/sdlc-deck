SDLC in Bhati

A customized SDLC, built for control

We start from a spec, then add two things of our own: a skill on every task, and a checker that must prove the work.

SpecA skill writes the requirements
Designdesign.md says how we will build it
TasksEach task in tasks.md names its skill
MakerBuilds the code using that skill
CheckerVerifies the work independently
EvidenceThe result is written to a file

Unique to our SDLC

ControlThe maker can't approve its own work, and a pass leaves proof.
