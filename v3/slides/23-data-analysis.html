Do's and don'ts: data analysis

Bring the agent to the query, not the data to the agent

When a task needs data, the agent should write the analysis. Real rows stay with you.

Share the schemaGive table and column names and types, not rows.
Let it write the queryThe agent writes the SQL or script. You run it on your side.
Share aggregatesCounts, totals and averages are fine. Row-level records are not.
Mask before you shareReplace names, phones, IDs and IPs with fake values first.
Use synthetic samplesGenerate a few made-up rows with the same shape as the real data.
Never connect to prodNo agent access to production databases, servers or backups.
Rule of thumbIf you would not post it in a public channel, don't paste it into an agent.
