# AI in the SDLC

A 24-slide HTML presentation covering spec-driven development, Claude Code, team skills, verification, security and deployment.

## Present

Open `index.html` in a desktop browser. Use Previous / Next or the slide selector. TV mode uses the full screen.

`combined-presentation.html` is a self-contained snapshot. `what-are-skills.html` contains the two-page API-controller comparison.

## Collaborate

Edit individual HTML files in `slides/`. To add a slide, copy `slide-template.html` and add its path and title to `slides.js`. The manifest controls presentation order. The combined snapshot does not automatically update when individual slides change.

See `README.txt` for detailed editing and TV presentation instructions.

## Skills session deck

`skills/index.html` is a separate 19-slide deck for the "Skills for coding agents" session: why and what skills are, frontmatter, progressive disclosure, portability, organizing, overrides, selective install, the ecosystem, and the maker–checker delivery principles. It uses the same viewer and slide style. Its slides are in `skills/slides/`, and `skills/slides.js` sets their order.
