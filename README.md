# AI SDLC in Bhati

**Live deck:** https://sanjeev23oct.github.io/sdlc-deck/v3/

Open `v3/index.html` in a browser, or use the link. Arrow keys move between slides, and `F` goes fullscreen.

## Add a slide

With Claude Code, run `/add-slide` and describe the slide. It follows [the skill](.claude/skills/add-slide/SKILL.md).

By hand, follow the same steps: add an HTML file to `v3/slides/` and list it in `v3/slides.js`. Shared styles are in `v3/theme.css`.

## Publish

Pushing to `main` updates the live deck. The repo and deck are public, so keep secrets and internal data out.
